# Dashboard REST API Specification

The Dashboard Backend provides REST APIs for executive SOC metrics, alerts management, and incident response workflows.

## REST Endpoints

### 1. Alert Ingestion (Agent API)
- **`POST /api/v1/alerts`**
  - **Headers**: `X-Agent-ID: <id>`, `X-Agent-Secret: <secret>`
  - Ingests a new security alert generated by a PRISM IDS agent. Broadcasts `NEW_ALERT` live event over WebSocket.

### 2. Alert Query & Search (SOC Analyst API)
- **`GET /api/v1/alerts`**
  - **Query Params**: `severity`, `status`, `protocol`, `detection_method`, `src_ip`, `dst_ip`, `agent_id`, `search`, `page`, `page_size`.
  - **Headers**: `Authorization: Bearer <jwt_access_token>`
  - Returns paginated alert list with total counts and page totals.

- **`GET /api/v1/alerts/{alert_id}`**
  - Returns detailed alert view.

### 3. Incident Management APIs
- **`GET /api/v1/incidents`**: List/search security incidents.
- **`POST /api/v1/incidents`**: Create a new security incident.
- **`PUT /api/v1/incidents/{id}/status`**: Update status (`OPEN`, `ACKNOWLEDGED`, `RESOLVED`, `REOPENED`).
- **`PUT /api/v1/incidents/{id}/assign`**: Assign analyst to incident.
- **`POST /api/v1/incidents/{id}/notes`**: Append investigation notes.

### 4. SOC Executive Metrics APIs
- **`GET /api/v1/dashboard/summary`**: Returns alert severity counts, open incidents, average risk score, top attacked hosts, top attacker IPs.
- **`GET /api/v1/dashboard/network`**: Returns protocol distribution percentages and network traffic statistics.
- **`GET /api/v1/dashboard/system`**: Returns CPU, memory, uptime, database status, and active WebSocket client count.
