# PRISM IDS SOC Dashboard Frontend Guide

The PRISM IDS SOC Dashboard is built with React 19, TypeScript, Vite, Tailwind CSS, Recharts, Zustand, and Lucide React icons.

## Design Aesthetic
- **Obsidian Dark Mode**: High-contrast, low-eyestrain dark palette tailored for Security Operations Center environments.
- **Glassmorphism**: Translucent cards with blurred backgrounds (`backdrop-blur-md`).
- **Neon Status Badges**: Distinct glowing indicators for Critical, High, Medium, Low, and Informational alert severities.
- **Real-Time Visual Indicators**: Live WebSocket connection badge with pulsing status dot.
